# 个人工作台 · P6

手机优先的本机工作台：每日计划、日报/周报一键复制、健身记录与加重建议、英语学习、垫付报销与个人支出分开记，以及主题/动态壁纸。纯前端，无账号、后端或云同步。

P0～P6 本地开发已完成。正式 PWA、便携单文件和通用服务器部署包均已构建；未操作你的服务器。桌面 Edge 的离线/更新/恢复检查已通过，正式 HTTPS 站点和手机安装、真实手机离线语音仍待按 **P6-验收清单.md** 确认。

## 在这台电脑打开

双击 **启动工作台.cmd**。首次复制到新电脑，需要先装 Node.js 22.12+ 或 24+；启动脚本会在缺依赖时执行 npm ci（首次需要联网）。启动后保留命令窗口，结束使用按 Ctrl+C。

也可以在项目目录打开 PowerShell：

```powershell
npm ci
npm run dev
```

这台电脑已安装依赖时省略 npm ci。打开显示的 `http://127.0.0.1:5173/`；端口被占用会报错，不自动换地址。请固定使用原来的浏览器与网址。

开发模式便于修改代码，不启用 Service Worker。要测试正式离线能力，执行：

```powershell
npm test
npm run build
npm run preview -- --port 4173
```

打开 preview 显示的地址，进入「更多 → 设置」，等状态标签显示「离线页面已准备好」，再断网刷新。preview 用于本机验收，不是生产服务器。

不同域名、协议或端口属于不同存储空间；从 5173 换到 4173 或正式 HTTPS 地址，需要在旧地址导出 JSON、在新地址导入。同源的根目录和子目录共享记录，离线缓存按目录隔离。

## 日常怎么用

- **计划**：新增日程、待办、重要事项，习惯打卡；凌晨按设置的日切归工作日，报账另按自然日期。
- **复盘**：首次建草稿带入计划，手工修改后不会被重入覆盖；后来新增事项用「补入新增事项」。点复制日报/周报，粘贴到工作群，输出纯文本。
- **健身**：可新增、编辑、删除自己的分化训练计划及动作组次；记录实际完成组，建议基于达标组数的历史重算。体重、腰/胸/肩/上臂围可记录趋势。
- **英语**：每天固定保存最多20个到期复习词＋5个新词、5句跟读、1篇短文、5道语法题。生词本/错题可重练，当天不重复推进正式排期。设置可导入六列 UTF-8 CSV 词库。
- **报账**：报销与个人支出分开；报销可加最多3张凭证，批量复制清单，按月导出 CSV。金额为整数分，图片只存本机 IndexedDB。
- **外观**：设置中选主题、毛玻璃浓度、流畅档位，导入图片或 MP4/WebM 壁纸。不能直接导入 Wallpaper Engine 场景包或创意工坊链接。

## 打包后怎样交付

`npm run build` 会先严格检查 TypeScript，再构建标准 PWA，随后用 PRD 指定的 vite-plugin-singlefile 额外生成便携版：

```text
dist/
  index.html                  正式 PWA 入口
  sw.js                       自动生成的版本缓存与更新逻辑
  manifest.webmanifest        应用名称、图标、启动地址
  assets/                     全部代码与样式分包
  icons/                      桌面、maskable、iOS 图标
  favicon.svg
  standalone.html             自包含便携文件，单独验收
```

服务器只需这组静态文件，无需上传源码、node_modules 或个人备份，也无需长期运行 npm。完整步骤与 Nginx 示例见 **服务器部署说明.md**；已经准备独立的 **个人工作台-服务器部署包.zip**，其中「网站文件」目录可直接上传。

可选 Vercel：导入此项目仓库，项目根目录选到 package.json 所在层，框架选 Vite，构建命令 `npm run build`，输出目录 `dist`，Node 22.12+ 或24+，无环境变量。仓库自带 vercel.json 缓存头配置。部署后按同一份 HTTPS 真机清单核对；本次未登录 Vercel 或执行远程部署。[Vercel 官方说明](https://vercel.com/docs/frameworks/frontend/vite)

## iPhone / 安卓安装到桌面

先用固定的正式 HTTPS 网址打开，在设置等待离线就绪。

- iPhone：Safari → 分享 → 添加到主屏幕；如果有「作为网页 App 打开」，保持开启，再添加。从桌面图标重开，检查独立窗口。[Apple 官方说明](https://support.apple.com/zh-cn/guide/iphone/iphea86e5236/ios)
- 安卓：Chrome/Edge 菜单 → 安装应用，或「安装并创建快捷方式 → 安装」；也可点工作台设置中出现的安装按钮。名称随浏览器变化。[Chrome 官方说明](https://support.google.com/chrome/answer/9658361?hl=zh-Hans&co=GENIE.Platform%3DAndroid)

从桌面重开后，开飞行模式再刷新，核对页面、记录和凭证。第一次访问必须联网。TTS 优先使用系统本机英语声线；没有本机声线会提示下载语音包，不能保证每台手机离线都出声。麦克风需要权限，录音只临时回放，关闭前可下载；不上传、不进入 JSON。

## 备份、恢复与换设备

1. 「更多 → 数据备份 → 导出 JSON 备份」，确认文件已保存。
2. 完整备份包含工作台全部已登记数据分区、凭证压缩图/缩略图、当前壁纸文件、训练计划、学习记录及队列、错题和导入词库；不包含临时录音、旧壁纸、其他应用数据或递归快照。
3. 超过50MB时显示分卷列表，逐个下载并保存在一起，齐卷后才更新上次导出。一次整套上限200MB；恢复时一次选齐同组全部分卷，顺序不限，缺卷/混卷/篡改拒绝。
4. 在新设备、同一浏览器或正式网址进入备份，选文件，核对数量，再确认恢复。恢复会替换本机数据；写入前有快照，失败回滚，损坏文件不覆盖。旧 structured/receipts 文件仍可恢复，旧文件没带的壁纸需另选。
5. 电脑和手机数据不自动同步。备份文件通过你自己的文件传输带到另一台设备后导入。

距上次导出严格超过7天，首页提示「该备份了」；首次使用从初始化算起，关闭后7天再提示。应用关闭时不发系统通知。安装图标与离线缓存都不替代数据备份。

## 更新与便携版

发布新版时按部署说明上传，sw.js 最后上传。客户端会完整准备新版后提示，等你保存表单/下载临时录音，再点确认更新；取消可继续当前版。其他窗口不会被强制刷新；未完成缓存的新版不取代旧版。缓存丢失时联网到设置点检查更新，可重新准备。

直接双击 `dist/standalone.html` 可在支持本地网页的浏览器打开。桌面 Edge 已实测 file:// 的读写、刷新保留与导出；手机文件预览器和不同浏览器行为不同，不承诺 PWA 安装与缓存，也不把便携文件当作长期唯一数据副本。

## 验证和代码边界

当前通过344条 Node 测试，涵盖算法、各模块保存、备份、分卷、失败回滚、离线缓存与更新状态；严格类型和双构建通过。性能、浏览器结果以 **P6-验证结果.json** 为准。

技术栈固定：Vite、React18、strict TypeScript、Tailwind、Zustand、dayjs、idb-keyval、Vitest。没有 UI/路由/图表库、在线词典、远程字体或运行时后端；仅加 PRD 指定的单文件构建插件。domain 是 Node 可单测的纯函数；store 互不导入，只写各自的所属 key；跨模块由页面 selector 和应用服务协调。

词库、句子、短文、语法与动作资料均为本项目自编，未引用外部内容数据集，因此没有新增 THIRD_PARTY_NOTICES.md。构建插件来源与版本记录在 package.json/lock 中。

**P6-交付说明.md** 列出本轮最简约定及待定项。P0～P5 文件保留为历史阶段记录，其中“未含壁纸/尚无分卷/后续PWA”等旧限制以本轮交付说明为准。
